Styling

Font, Colour & Spacing

font-family and font-size set the typeface; color and background-color set the text and fill colours; padding, margin and border shape the box.

CSS 
.box {
  font-family: Arial, sans-serif;
  font-size: 18px;
  color: white;
  background-color: steelblue;
  padding: 20px;
  margin: 10px;
  border: 2px solid black;
}
Result
Layout

Centering a Div with Flexbox

display: flex + justify-content: center (left/right) + align-items: center (top/bottom) centers a box on both axes. For horizontal-only centering, margin: 0 auto also works.

CSS 
body {
  display: flex;
  justify-content: center;
  align-items: center;
  height: 100vh;
}

/* horizontal-only alternative */
.box {
  width: 200px;
  margin: 0 auto;
}
Result
Colour

Colour Names, RGB & Hex

CSS accepts a colour written three ways — a plain name, an rgb() triplet, or a hex code — and all three are fully interchangeable.

CSS 
/* all three lines do the same thing */
color: red;
color: rgb(255, 0, 0);
color: #FF0000;
Result
Content

Lists: <ul>, <ol> & <li>

<ul> makes an unordered (bulleted) list; <ol> makes an ordered (numbered) list. Each item goes inside its own <li>.

HTML 
<ul>
  <li>Apples</li>
  <li>Bananas</li>
  <li>Milk</li>
</ul>

<ol>
  <li>Preheat oven</li>
  <li>Mix batter</li>
  <li>Bake 20 min</li>
</ol>
Result
Content

Tables: <table>, <td> & <th>

<table> holds rows (<tr>); <th> is a header cell, <td> is a normal data cell.

HTML 
<table>
  <tr>
    <th>Name</th>
    <th>Age</th>
  </tr>
  <tr>
    <td>Ansel</td>
    <td>16</td>
  </tr>
</table>
Result
Content

Forms & Inputs

<input> collects data — type="text" for words, type="number" for integers, type="date" for a date picker. <button type="submit"> sends the form.

HTML 
<form>
  <input type="text"
    placeholder="Your name">
  <input type="number"
    placeholder="Your age">
  <input type="date">
  <button type="submit">
    Submit
  </button>
</form>
Result
