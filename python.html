Part One

Python Basics

Install Python, then get comfortable with the five data types you'll use every day: strings, integers, variables, tuples and dictionaries.

Installing Python

Pick your computer below and run the commands in your terminal.

Terminal 
brew install python
python3 --version

brew installs the latest stable release; python3 --version confirms it worked. Don't have Homebrew? Install it first from brew.sh.

PowerShell 
winget install Python.Python.3.14
python --version
pip --version

winget installs the latest release from the Microsoft Store catalogue. Both commands confirm Python and pip are ready.

Data Types

Strings — text

A string holds text, written inside quotes. Combine strings with +.

Python 
name = "Ansel"
print("Hello, " + name)
OutputHello, Ansel
Data Types

Integers — whole numbers

An integer is a whole number, positive or negative, used for counting and maths.

Python 
age = 16
print(age + 4)
Output20
Data Types

Variables — named boxes

A variable stores a value under a name. Its value can change (be reassigned) later.

Python 
score = 10
score = score + 5
print(score)
Output15
Data Types

Tuples — fixed, ordered lists

A tuple groups several values in order, written with ( ). Once created, it cannot be changed. fruits[1] is the 2nd item — Python counts from 0.

Python 
fruits = ("apple", "banana", "cherry")
print(fruits[1])
Outputbanana
Data Types

Dictionaries — key → value pairs

A dictionary stores data as key → value pairs, written with { }. Look up any value instantly using its key — much faster than searching a list.

Python 
student = {
    "name": "Ansel",
    "age": 16,
    "class": "Y11"
}

print(student["name"])
print(student["age"])
OutputAnsel
16

Key ideas

Keythe label you look values up by, e.g. "name"
Valuethe data stored under that key, e.g. "Ansel"
Add / updatestudent["age"] = 17 sets or overwrites a value
