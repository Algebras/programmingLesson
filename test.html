QUESTION 1 · PYTHON · VARIABLES & DICTIONARIES

Add up a shopping cart

A shop sells duck, chicken and fish. Create three variables — duck, chicken and fish — and set each one to a price (a whole number, in dollars). Add the three variables together to get a total. Then create a dictionary called cart and store that total inside it under the key "totalCost". Finally, print the dictionary.

Solution
Python 
duck = 18
chicken = 9
fish = 12

total = duck + chicken + fish

cart = {}
cart["totalCost"] = total

print(cart)
Output{'totalCost': 39}

Any three prices work — what matters is that duck + chicken + fish is stored under the "totalCost" key of the dictionary.

QUESTION 2 · HTML & CSS · LAYOUT

Center a box on the page

Write the CSS that centers a <div class="box"> both horizontally and vertically in the middle of the whole page, using flexbox.

Solution
CSS 
body {
  display: flex;
  justify-content: center;
  align-items: center;
  height: 100vh;
}

justify-content: center centers left/right, align-items: center centers top/bottom.

QUESTION 3 · HTML & CSS · TAGS

Pick the right tag

You need a numbered step-by-step list. Which tag wraps the list, and which tag wraps each step?

Solution
HTML 
<ol>
  <li>Preheat oven</li>
  <li>Mix batter</li>
  <li>Bake 20 min</li>
</ol>

<ol> — an ordered (numbered) list. If order didn't matter, <ul> (bulleted) would be correct instead. Each step is an <li> either way.
